# Pull Request Guidelines

Standard process and format for creating pull requests.

## Core Rules

1. Create all pull requests as a **draft**. Only mark as ready for review when the user explicitly instructs you to do so.
2. **AI Disclosure**: Every pull request body MUST start at the very top with a callout declaring that the PR was generated by an AI agent.

## Required PR Template

```markdown
> [!NOTE]
> 🤖 **Generated by AI Agent**
> - **Model**: <model> <reasoning_level> (if known)
> - **Harness**: <harness>
```
