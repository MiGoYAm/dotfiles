# Pull Request Guidelines

## Core Rules

1. **AI Disclosure**: Every pull request body and comment MUST start at the very top with a callout declaring that the PR was generated by an AI agent.
2. Fix up or squash follow-up commits into the commits they amend when they change code or behavior introduced in the same PR. This applies to `style:`, `refactor:`, `fix:`, and similar prefixes; judge by the change, not the prefix. Keep independent changes as separate commits.

## Required PR Template

```markdown
> 🤖 **Generated by AI Agent** <model> <reasoning_level> in <harness>
```
